## whoami

I'm **Monisha**, an IT undergraduate from Erode, Tamil Nadu, exploring the world of software. I enjoy building projects across web development, AI, cybersecurity and blockchain, from a phishing URL analyser to a tamper-proof complaint system. I sharpen my problem-solving daily on LeetCode, HackerRank and GeeksforGeeks. Always learning, always shipping.
